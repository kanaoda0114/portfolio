## 1. ファイルの構成

| シート | 目的 | 1行の単位 |
|---|---|---|
| **返品計上一覧** | 絞り込み・集計・販売管理システムへの入力に使う | 返品明細1行 |
| **伝票別（伝票番号）** | 人が見て確かめる・印刷する。消費税と合計を確認する | 返品伝票1枚＝1シート |

### 共通の見た目
- 表には**罫線**を引く（細線、見出しの下は太線）
- 見出し行は色つき・太字、1行目を固定（スクロールしても見える）、フィルター付き
- 金額・単価は `#,##0`（桁区切り）、マイナスは赤字、日付は `yyyy/mm/dd`
- 品番・枝番・伝票番号・会社コード・理由コードは「文字列」（先頭の 0 が消えないように）
- 「=」で始まる文字も数式にしない（数式インジェクション対策）
- 印刷：A4横・1ページの幅に収める・見出し行を毎ページ印刷

最終行の下に**合計行**（数量・金額（税込）の合計）をつける。
消費税は伝票ごと・税率ごとに計算するため、一覧には明細ごとの消費税は出さない（「伝票別」シートに出す）。

## 3. シート「伝票別」

```
│ 登録番号  T1234567890123             計上月    2026/11（締め日 11/20）  │
├────┬──────────┬────┬──────────────┬────┬────────┬────────┬────┬───────┤
│ No │ 品番      │枝番 │ 商品名         │数量 │単価(税込)│金額(税込)│税率│ 照合   │

├────┴──────────┴────┴──────────────┴────┴────────┼────────┼────┴───────┤
│                                  10%対象 合計（税込） │  1,738 │            │
│                                       うち消費税     │    158 │            │
│                                        税抜金額     │  1,580 │            │
│                                   8%対象 合計（税込） │      0 │            │
│                                       うち消費税     │      0 │            │
│                                        税抜金額     │      0 │            │
│                                    返品合計（税込）   │  1,738 │            │
└───────────────────────────────────────────────────┴────────┴────────────┘

```

### 消費税の計算（単価が税込の場合）
- **伝票ごと・税率ごと**に、税込金額を合計する（値引の行も含める）
- うち消費税 ＝ 税込合計 × 税率 ÷（100 ＋ 税率）
  - 例：10%対象 1,738円 → 1,738 × 10 ÷ 110 ＝ 158.0 → **158円**
- 端数処理は、**税率ごとに1回だけ**、取引先マスタの「消費税の端数処理」で行う（明細1行ずつ計算して足さない。インボイス制度のルール）
- 税抜金額 ＝ 税込合計 − うち消費税

### 値引の按分（Q15）
値引の税率が `按分` の行は、同じ伝票の通常の行の、税率ごとの税込合計の比率で分ける。

| | 10%対象 | 8%対象 | 合計 |
|---|---|---|---|
| 通常の行の税込合計 | 1,000 | 500 | 1,500 |
| 比率 | 2/3 | 1/3 | |
| 値引 −150 を按分 | **−100** | **−50** | −150 |

- 1円未満の端数は、税込合計が大きいほうの税率に寄せる（分けた合計が元の値引額と必ず同じになる）
- 分けたあとの金額で、税率ごとの合計（税込）と消費税を計算する

### 締め日を過ぎた処理（Q14）
確定した日が返品日の締め日を過ぎている伝票は、**次の締め期間に計上**する（翌月の請求で相殺）。
シートの上に赤字で「**締め日（11/20）を過ぎたため、12月計上にしました**」と表示する（要件定義書 S8）。

## 4. 出力しない場合

| 条件 | 対応 |
|---|---|
| `確定済み` でない伝票 | 出力しない。理由「確定していません」 |
| エラー（要件定義書 F4・F9）がある伝票 | 出力しない。理由としてエラー内容を表示 |
| 警告だけがある伝票 | 出力する。一覧の「照合結果」列と画面に警告を表示 |
| 出力対象が0件 | Excelを作らず「出力できる伝票がありません」と表示 |
